# 📦 cuddly-octo-guacamole

Repository containing everything related to the final project of the subject of Medical Image Processing in the Master's Degree in Intelligent Systems at UIB.

------------------------------------------------------------------------

## 🛠️ Installation

### 1. Clone the repository

git clone https://github.com/Randenlomnis0/cuddly-octo-guacamole.git\

cd cuddly-octo-guacamole

------------------------------------------------------------------------

### 2. Create environment and install dependencies

I use a local Conda environment and Python 3.14.4.

------------------------------------------------------------------------

### 3. Download required model file

This repository does NOT include the trained model weights (`.pth`
file).

You must download it separately and place it in the root
directory.

I downloaded it from the following link: https://www.kaggle.com/datasets/simayyamuruysal/sam-vit-h-4b8939-pth.

------------------------------------------------------------------------

### 4. Add FORISI folder

This folder isn't included in the repository and is necessary for propper execution. It can be downloaded from the link in the project proposal.

------------------------------------------------------------------------

## ▶️ Usage

### Run the main script

python src/main.py
